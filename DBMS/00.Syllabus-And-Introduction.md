# Introduction to DBMS

## What is DBMS?
- Database Management System
- Software that manages databases — handles storage, retrieval, and manipulation of data
- Acts as an interface between users and the database

## Real-Life Examples
- Banking — account info, transactions
- Railway reservation — seat availability, bookings
- University — student records, courses, grades
- E-commerce — products, orders, customers

## Why DBMS?
- Centralized data management
- Data consistency and integrity
- Multi-user access with concurrency control
- Security and access control
- Backup and recovery

## Popular DBMS
- MySQL, PostgreSQL, Oracle, SQL Server (relational)
- MongoDB, Firebase, DynamoDB (non-relational)

## Topics in DBMS
- Architecture (2-tier, 3-tier, three schema)
- ER Model and relationships
- Normalization and functional dependencies
- SQL and relational algebra
- Transactions, concurrency control
- Indexing and file organization
- Recovery mechanisms
