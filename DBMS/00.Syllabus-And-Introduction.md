## Introduction to DBMS (Lec-2)

### What is DBMS?
- Database Management System
- Software to manage databases efficiently
- Handles storage, retrieval, and manipulation of data

### Real-Life Examples
- Banking systems — account info, transactions
- Railway reservation — ticket booking, seat availability
- University — student records, courses, grades
- E-commerce — product catalogs, orders, customers

### Why DBMS?
- Centralized data management
- Data consistency and integrity
- Multi-user access with concurrency control
- Security and access control
- Backup and recovery mechanisms

### Popular DBMS
- MySQL
- PostgreSQL
- Oracle
- SQL Server
- MongoDB (NoSQL)

---

## Notes
- DBMS acts as an interface between users and the database
- Eliminates data redundancy and inconsistency
- Provides efficient data access and retrieval
