# Functions

## Aggregate Functions
- Perform a calculation on a set of values and return a single value

### COUNT
```sql
-- Count total number of employees
SELECT COUNT(emp_id) FROM employee;

-- Count employees with a supervisor
SELECT COUNT(super_id) FROM employee;
-- Note: NULL values are NOT counted
```

### AVG
```sql
-- Average salary of all male employees
SELECT AVG(salary) FROM employee WHERE sex = 'M';
```

### SUM
```sql
-- Total salary of all employees
SELECT SUM(salary) FROM employee;
```

### MAX / MIN
```sql
SELECT MAX(salary) FROM employee;
SELECT MIN(salary) FROM employee;
```

---

## GROUP BY
- Groups rows with the same value in a column
- Used with aggregate functions to get per-group results

```sql
-- Count employees by sex
SELECT sex, COUNT(sex) FROM employee GROUP BY sex;

-- Total sales per employee
SELECT emp_id, SUM(total_sales) FROM works_with GROUP BY emp_id;

-- Total sales per client
SELECT client_id, SUM(total_sales) FROM works_with GROUP BY client_id;
```

---

## Notes
- Aggregate functions ignore `NULL` values (except `COUNT(*)`)
- `COUNT(*)` counts all rows including NULLs
- `COUNT(column)` counts only non-NULL values in that column
- `GROUP BY` must reference a column that's also in `SELECT`
- Can combine `WHERE` with `GROUP BY` — `WHERE` filters before grouping
