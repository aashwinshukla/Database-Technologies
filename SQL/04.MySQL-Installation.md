# MySQL Installation

## Windows Installation

### Steps
- Download MySQL installer from mysql.com → Downloads → MySQL Installer for Windows
- Choose "mysql-installer-community" (larger file, includes everything)
- Run the installer
- Setup type: choose **Developer Default** or **Custom**
- During config:
  - Config type: Development Computer
  - Port: 3306 (default)
  - Set a root password — remember this
- Also installs MySQL Workbench automatically

### MySQL Workbench
- GUI tool to interact with MySQL
- After install, open Workbench → connect using root credentials
- Click the local instance to open a query editor

---

## Mac Installation

### Steps
- Download MySQL Community Server from mysql.com → Downloads → MySQL Community Server
- Choose macOS version → download the `.dmg` file
- Run the installer, follow the steps
- At the end it will show a **temporary root password** — copy it immediately
- Go to System Preferences → MySQL → Start MySQL Server

### Connecting via Terminal (optional)
```bash
/usr/local/mysql/bin/mysql -u root -p
```
- Enter the temporary password
- Change password:
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'newpassword';
```

### MySQL Workbench on Mac
- Download separately from mysql.com → Downloads → MySQL Workbench
- Connect using root and the new password

---

## General Notes
- MySQL default port: **3306**
- Root user = superuser with full access
- Always set a strong root password
- MySQL Workbench is optional but makes things easier visually
