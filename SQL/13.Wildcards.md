# Wildcards

## What are Wildcards?
- Used to match patterns in string values
- Used with the `LIKE` keyword in a `WHERE` clause

## Wildcard Characters

| Symbol | Meaning |
|--------|---------|
| `%` | Any number of characters (including zero) |
| `_` | Exactly one character |

---

## Examples

### % — Any sequence of characters
```sql
-- Find clients whose name ends with 'LLC'
SELECT * FROM client WHERE client_name LIKE '%LLC';

-- Find clients whose name contains 'school'
SELECT * FROM client WHERE client_name LIKE '%school%';

-- Find clients whose name starts with 'a'
SELECT * FROM client WHERE client_name LIKE 'a%';
```

### _ — Exactly one character
```sql
-- Find employees born in October (month = 10)
SELECT * FROM employee WHERE birth_day LIKE '____-10%';
-- 4 underscores for the year, then -10 for October

-- Find employees born in the 1970s
SELECT * FROM employee WHERE birth_day LIKE '197_-%';
```

---

## Notes
- `LIKE` is case-insensitive in most RDBMS by default
- `%` is the most commonly used wildcard
- Can combine `%` and `_` in the same pattern
- Wildcards only work with strings — not numbers or dates directly (use string format for dates as shown above)
