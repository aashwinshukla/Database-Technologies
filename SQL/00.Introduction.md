# Introduction

- Course covers SQL from scratch — no prior experience needed
- SQL = Structured Query Language
- Used to interact with relational databases
- One of the most in-demand skills for developers, data analysts, etc.

## What this course covers
- Core database concepts (what a DB is, tables, keys)
- SQL syntax and basics
- MySQL setup (Windows & Mac)
- Creating tables, inserting data, constraints
- Querying data — basic to advanced
- Functions, wildcards, unions, joins
- Nested queries, triggers, on delete behavior
- ER diagrams — designing and converting to schemas

## Tools used
- MySQL — the RDBMS used throughout the course
- MySQL Workbench — GUI to interact with the database
