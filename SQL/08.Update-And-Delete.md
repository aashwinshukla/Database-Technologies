# Update & Delete

## UPDATE

### Basic Syntax
```sql
UPDATE table_name
SET column1 = value1, column2 = value2
WHERE condition;
```

### Examples
```sql
-- Change major of a specific student
UPDATE student
SET major = 'Bio'
WHERE major = 'Biology';

-- Update multiple columns
UPDATE student
SET name = 'Tom', major = 'Undecided'
WHERE student_id = 1;

-- Update using OR
UPDATE student
SET major = 'Biochemistry'
WHERE major = 'Biology' OR major = 'Chemistry';

-- Update all rows (no WHERE)
UPDATE student
SET major = 'Undecided';
```

## DELETE

### Basic Syntax
```sql
DELETE FROM table_name
WHERE condition;
```

### Examples
```sql
-- Delete a specific row
DELETE FROM student
WHERE student_id = 5;

-- Delete based on a condition
DELETE FROM student
WHERE name = 'Tom' AND major = 'Undecided';

-- Delete all rows (no WHERE)
DELETE FROM student;
```

## Notes
- Always use `WHERE` with `UPDATE` and `DELETE` — without it, ALL rows are affected
- `WHERE` can use: `=`, `<>` (not equal), `<`, `>`, `<=`, `>=`, `AND`, `OR`
- `<>` means "not equal to" in SQL
- Deleting a row doesn't reset `AUTO_INCREMENT` counter
- Can't delete a row that's being referenced by a foreign key (unless ON DELETE is set)
