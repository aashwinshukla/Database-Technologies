# Basic Queries

## SELECT
```sql
-- Get all columns
SELECT * FROM student;

-- Get specific columns
SELECT name, major FROM student;
```

## ORDER BY
```sql
-- Ascending (default)
SELECT * FROM student ORDER BY name;

-- Descending
SELECT * FROM student ORDER BY name DESC;

-- Order by multiple columns
SELECT * FROM student ORDER BY major, student_id;
```

## LIMIT
```sql
-- Get only first 2 rows
SELECT * FROM student LIMIT 2;
```

## WHERE (Filtering)
```sql
SELECT * FROM student WHERE major = 'Biology';

SELECT * FROM student WHERE student_id <= 3;

SELECT * FROM student WHERE major = 'Biology' AND name = 'Jack';

SELECT * FROM student WHERE major = 'Biology' OR major = 'Chemistry';

-- Not equal
SELECT * FROM student WHERE major <> 'Biology';
```

## IN
```sql
-- Match against a list of values
SELECT * FROM student WHERE name IN ('Claire', 'Kate', 'Mike');
```

## Combining Everything
```sql
SELECT name, major
FROM student
WHERE major IN ('Biology', 'Chemistry')
ORDER BY name DESC
LIMIT 3;
```

## Notes
- `SELECT *` = get all columns
- `ORDER BY` default is `ASC` (ascending)
- `LIMIT` always goes at the end
- `WHERE` filters rows before returning results
- Comparison operators: `=`, `<>`, `<`, `>`, `<=`, `>=`
- Logical operators: `AND`, `OR`, `IN`
