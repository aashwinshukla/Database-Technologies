# Inserting Data

## Basic Syntax
```sql
INSERT INTO table_name VALUES(value1, value2, ...);
```
- Values must be in the same order as the columns in the table
- All columns must be provided

## Example
```sql
INSERT INTO student VALUES(1, 'Jack', 'Biology');
INSERT INTO student VALUES(2, 'Kate', 'Sociology');
INSERT INTO student VALUES(3, 'Claire', 'Chemistry');
INSERT INTO student VALUES(4, 'Jack', 'Biology');
```

## Inserting with Specific Columns
```sql
INSERT INTO student(student_id, name) VALUES(5, 'Mike');
```
- Columns not mentioned will be set to `NULL`
- Useful when some columns are optional

## Viewing All Data in a Table
```sql
SELECT * FROM student;
```

## Notes
- Strings go in single quotes `' '`
- Numbers do not need quotes
- If a column is `NOT NULL` and you don't provide a value → error
- `NULL` = no value / unknown — not the same as 0 or empty string
- Inserting duplicate primary key values → error
