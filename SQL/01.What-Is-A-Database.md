# What is a Database?

## Basic Definition
- A database is any collection of related information
- e.g. phone book, shopping list, Facebook user info — all are "databases"
- Databases can be stored on paper, in the mind, or on a computer

## Database Management System (DBMS)
- A DBMS is software that helps users create and manage databases
- Handles security, backups, importing/exporting, concurrency, etc.
- Makes it easier to interact with data

## Types of Databases

### Relational Databases (SQL)
- Organize data into tables (rows and columns)
- Tables can relate to each other
- Uses SQL to interact
- Examples: MySQL, PostgreSQL, Oracle, MS SQL Server

### Non-Relational Databases (NoSQL)
- Data not stored in traditional tables
- Can store: JSON, XML, graphs, key-value pairs, etc.
- Examples: MongoDB, DynamoDB, Apache Cassandra, Firebase
- Better for unstructured or rapidly changing data

## Relational vs Non-Relational
- Relational = structured, strict schema, great for complex queries
- Non-relational = flexible schema, scales easily, good for big/unstructured data

## DBMS vs RDBMS
- DBMS = manages any type of database
- RDBMS = specifically manages relational databases
- SQL is used with RDBMS

## SQL (Structured Query Language)
- Language used to interact with relational databases
- Used to: create, read, update, delete data (CRUD)
- Each RDBMS has slight variations in SQL syntax, but core is the same
- SQL is a standard — defined by IEEE

## Queries
- A query = a request made to the database
- Can ask for specific info, insert new data, update existing, delete, etc.
