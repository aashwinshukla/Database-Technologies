# Triggers

## What is a Trigger?
- A block of SQL code that automatically runs when a specific event occurs on a table
- Events: `INSERT`, `UPDATE`, `DELETE`
- Can run `BEFORE` or `AFTER` the event

## Basic Syntax
```sql
DELIMITER $$
CREATE TRIGGER trigger_name
    BEFORE/AFTER INSERT/UPDATE/DELETE
    ON table_name FOR EACH ROW
BEGIN
    -- SQL statements
END$$
DELIMITER ;
```

- `DELIMITER $$` — changes the delimiter temporarily so the `;` inside the trigger doesn't end the whole statement
- `FOR EACH ROW` — trigger fires once per affected row

---

## Example — Log when a new employee is added

### Create a trigger_test table first
```sql
CREATE TABLE trigger_test (
    message VARCHAR(100)
);
```

### Create the trigger
```sql
DELIMITER $$
CREATE TRIGGER my_trigger
    AFTER INSERT
    ON employee FOR EACH ROW
BEGIN
    INSERT INTO trigger_test VALUES('added new employee');
END$$
DELIMITER ;
```
- Every time a new employee is inserted → a message is logged in `trigger_test`

---

## NEW and OLD keywords

- `NEW` — refers to the new row being inserted/updated
- `OLD` — refers to the row before update/delete

```sql
-- Log the name of the newly added employee
DELIMITER $$
CREATE TRIGGER my_trigger
    AFTER INSERT
    ON employee FOR EACH ROW
BEGIN
    INSERT INTO trigger_test VALUES(NEW.first_name);
END$$
DELIMITER ;
```

---

## Trigger with Conditional Logic
```sql
DELIMITER $$
CREATE TRIGGER my_trigger
    AFTER INSERT
    ON employee FOR EACH ROW
BEGIN
    IF NEW.sex = 'M' THEN
        INSERT INTO trigger_test VALUES('added male employee');
    ELSEIF NEW.sex = 'F' THEN
        INSERT INTO trigger_test VALUES('added female employee');
    ELSE
        INSERT INTO trigger_test VALUES('added other employee');
    END IF;
END$$
DELIMITER ;
```

---

## Dropping a Trigger
```sql
DROP TRIGGER my_trigger;
```

---

## Notes
- Triggers are invisible to the user — run automatically in the background
- Useful for logging, auditing, enforcing business rules
- `NEW` is available for `INSERT` and `UPDATE`
- `OLD` is available for `UPDATE` and `DELETE`
- Can only have one action per trigger (use `BEGIN...END` for multiple statements)
