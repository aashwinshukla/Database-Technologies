# Creating Tables

## Basic Syntax
```sql
CREATE TABLE table_name (
    column1 datatype constraint,
    column2 datatype constraint,
    ...
);
```

## Example
```sql
CREATE TABLE student (
    student_id INT PRIMARY KEY,
    name VARCHAR(20),
    major VARCHAR(20)
);
```

## Viewing the Table Structure
```sql
DESCRIBE student;
```

## Deleting a Table
```sql
DROP TABLE student;
```

## Adding a Column to Existing Table
```sql
ALTER TABLE student ADD gpa DECIMAL(3, 2);
```

## Removing a Column from Existing Table
```sql
ALTER TABLE student DROP COLUMN gpa;
```

## Notes
- `PRIMARY KEY` = uniquely identifies each row, automatically NOT NULL + UNIQUE
- Column order matters for readability but not functionality
- Always define a primary key
- `VARCHAR(20)` = string up to 20 characters
- `DECIMAL(3, 2)` = 3 total digits, 2 after decimal (e.g. 3.65)
- Table and column names are case-insensitive in most systems but keep consistent
