# Constraints

## What are Constraints?
- Rules applied to columns when creating a table
- Restrict the type of data that can be stored
- Defined in `CREATE TABLE` or added via `ALTER TABLE`

## Common Constraints

### NOT NULL
- Column cannot have a NULL value
```sql
name VARCHAR(20) NOT NULL
```

### UNIQUE
- All values in the column must be different
```sql
name VARCHAR(20) UNIQUE
```

### DEFAULT
- Sets a default value if none is provided
```sql
major VARCHAR(20) DEFAULT 'Undecided'
```

### AUTO_INCREMENT
- Automatically increments integer value for each new row
- Common for primary keys — no need to manually provide the ID
```sql
student_id INT AUTO_INCREMENT
```

### PRIMARY KEY
- Combines NOT NULL + UNIQUE
- Uniquely identifies each row
```sql
student_id INT PRIMARY KEY
```

### Example Table with Constraints
```sql
CREATE TABLE student (
    student_id INT AUTO_INCREMENT,
    name VARCHAR(20) NOT NULL,
    major VARCHAR(20) DEFAULT 'Undecided',
    PRIMARY KEY(student_id)
);
```

### Inserting into a table with AUTO_INCREMENT
```sql
INSERT INTO student(name, major) VALUES('Jack', 'Biology');
INSERT INTO student(name, major) VALUES('Kate', 'Sociology');
```
- No need to provide `student_id` — it auto-assigns 1, 2, 3...

## Notes
- Multiple constraints can be applied to the same column
- `PRIMARY KEY` can be defined inline or at the end of the column list
- `AUTO_INCREMENT` only works on integer columns
