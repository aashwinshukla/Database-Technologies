# Nested Queries

## What are Nested Queries?
- A query inside another query
- Also called subqueries
- The inner query runs first, its result is used by the outer query

## Basic Syntax
```sql
SELECT column
FROM table
WHERE column IN (
    SELECT column
    FROM table
    WHERE condition
);
```

---

## Examples

### Find names of all employees who have sold over 30,000 to a single client
```sql
SELECT employee.first_name, employee.last_name
FROM employee
WHERE employee.emp_id IN (
    SELECT works_with.emp_id
    FROM works_with
    WHERE works_with.total_sales > 30000
);
```

### Find all clients who are handled by the branch that Michael Scott manages
```sql
-- Step 1: find Michael's emp_id
-- Step 2: find branch where mgr_id = Michael's emp_id
-- Step 3: find clients for that branch

SELECT client.client_name
FROM client
WHERE client.branch_id = (
    SELECT branch.branch_id
    FROM branch
    WHERE branch.mgr_id = (
        SELECT employee.emp_id
        FROM employee
        WHERE employee.first_name = 'Michael' AND employee.last_name = 'Scott'
        LIMIT 1
    )
);
```

---

## Notes
- Inner query executes first, result passed to outer query
- Use `IN` when the subquery returns multiple rows
- Use `=` when the subquery returns exactly one value
- Can nest multiple levels deep but gets hard to read quickly
- Joins can often do the same thing as nested queries — sometimes more efficiently
