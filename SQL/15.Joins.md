# Joins

## What are Joins?
- Combine rows from two or more tables based on a related column
- Used to get data spread across multiple tables in one query

---

## Types of Joins

### INNER JOIN (default JOIN)
- Returns rows where there is a match in **both** tables
- Rows with no match in either table are excluded

```sql
SELECT employee.emp_id, employee.first_name, branch.branch_name
FROM employee
JOIN branch
ON employee.emp_id = branch.mgr_id;
```

### LEFT JOIN
- Returns **all rows from the left table** + matched rows from the right
- If no match in right table → NULL for right table columns

```sql
SELECT employee.emp_id, employee.first_name, branch.branch_name
FROM employee
LEFT JOIN branch
ON employee.emp_id = branch.mgr_id;
```

### RIGHT JOIN
- Returns **all rows from the right table** + matched rows from the left
- If no match in left table → NULL for left table columns

```sql
SELECT employee.emp_id, employee.first_name, branch.branch_name
FROM employee
RIGHT JOIN branch
ON employee.emp_id = branch.mgr_id;
```

### FULL OUTER JOIN
- Returns all rows from **both** tables
- NULL where there is no match on either side
- Not supported directly in MySQL — can simulate with `LEFT JOIN UNION RIGHT JOIN`

---

## Visual Summary

| Join Type | Left Table | Right Table |
|-----------|------------|-------------|
| INNER JOIN | matched only | matched only |
| LEFT JOIN | all rows | matched or NULL |
| RIGHT JOIN | matched or NULL | all rows |
| FULL OUTER | all rows | all rows |

---

## Notes
- `ON` specifies the condition to match rows between tables
- Always specify `table.column` when column names exist in multiple tables
- `JOIN` without a type = `INNER JOIN` by default
- Can join more than two tables in one query
- The order of tables matters for LEFT and RIGHT joins
