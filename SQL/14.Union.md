# Union

## What is UNION?
- Combines the results of two or more `SELECT` statements into one result set
- Stacks results vertically (rows on top of each other)

## Rules
- Each `SELECT` must have the same number of columns
- Columns must have compatible data types
- Column names in the final result come from the first `SELECT`

## Basic Syntax
```sql
SELECT column1 FROM table1
UNION
SELECT column1 FROM table2;
```

## Examples

### Get a list of all employee and branch names together
```sql
SELECT first_name FROM employee
UNION
SELECT branch_name FROM branch;
```

### Get a list of all employee names, branch names, and client names
```sql
SELECT first_name AS company_names FROM employee
UNION
SELECT branch_name FROM branch
UNION
SELECT client_name FROM client;
```

### Get all money spent or earned by the company
```sql
-- Employee salaries (money out) + total sales (money in)
SELECT salary FROM employee
UNION
SELECT total_sales FROM works_with;
```

## UNION vs UNION ALL
```sql
-- UNION removes duplicates (default)
SELECT first_name FROM employee
UNION
SELECT branch_name FROM branch;

-- UNION ALL keeps duplicates
SELECT first_name FROM employee
UNION ALL
SELECT branch_name FROM branch;
```

## Notes
- `UNION` automatically removes duplicate rows
- `UNION ALL` keeps all rows including duplicates
- Column count and data types must match across all SELECT statements
- Use aliases in the first SELECT to name the output column
