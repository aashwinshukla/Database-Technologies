# SQL Basics

## What is SQL?
- Structured Query Language
- Used to interact with relational database management systems (RDBMS)
- Tells the RDBMS what you want to do with the data

## SQL is not always case-sensitive
- Keywords like `SELECT`, `FROM`, `WHERE` are conventionally written in caps
- But most RDBMS won't break if you use lowercase
- Table/column names depend on the system

## Four Types of SQL Languages

### 1. Data Query Language (DQL)
- Used to query/retrieve data
- Main command: `SELECT`

### 2. Data Definition Language (DDL)
- Used to define or modify database structure
- Commands: `CREATE`, `ALTER`, `DROP`

### 3. Data Manipulation Language (DML)
- Used to insert, update, delete data
- Commands: `INSERT`, `UPDATE`, `DELETE`

### 4. Data Control Language (DCL)
- Used to control access/permissions
- Commands: `GRANT`, `REVOKE`

## Basic Query Structure
```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

## Common Data Types
| Type | Description |
|------|-------------|
| `INT` | Whole numbers |
| `DECIMAL(m, d)` | Decimal numbers — m = total digits, d = digits after decimal |
| `VARCHAR(n)` | Variable-length string, max n characters |
| `BLOB` | Binary Large Object — stores large data (images, files) |
| `DATE` | Format: `YYYY-MM-DD` |
| `TIMESTAMP` | Format: `YYYY-MM-DD HH:MM:SS` |

## Misc Notes
- Queries end with a semicolon `;`
- Comments: `--` for single line, `/* */` for multi-line
- SQL works across most RDBMS with minor syntax differences
