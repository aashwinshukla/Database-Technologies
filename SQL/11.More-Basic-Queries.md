# More Basic Queries

## Using the Company Database
- All examples below use the company database tables: `employee`, `branch`, `client`, etc.

## SELECT with Specific Columns
```sql
-- Get all employees
SELECT * FROM employee;

-- Get only first and last name
SELECT first_name, last_name FROM employee;

-- Get with alias (rename column in output)
SELECT first_name AS forename, last_name AS surname FROM employee;
```

## SELECT DISTINCT
```sql
-- Get unique values only (no duplicates)
SELECT DISTINCT sex FROM employee;
SELECT DISTINCT branch_id FROM employee;
```

## WHERE with Multiple Conditions
```sql
SELECT * FROM employee WHERE sex = 'F' AND salary > 50000;

SELECT * FROM employee WHERE branch_id = 2 OR branch_id = 3;
```

## ORDER BY
```sql
SELECT * FROM employee ORDER BY salary DESC;

SELECT * FROM employee ORDER BY sex, salary DESC;
```

## LIMIT
```sql
SELECT * FROM employee LIMIT 5;
```

## NULL Checks
```sql
-- Rows where super_id is NULL
SELECT * FROM employee WHERE super_id IS NULL;

-- Rows where super_id is NOT NULL
SELECT * FROM employee WHERE super_id IS NOT NULL;
```

## Notes
- `AS` = alias — only changes the output label, not the actual column name
- `DISTINCT` removes duplicate rows from results
- `IS NULL` / `IS NOT NULL` — must use these for NULL checks, not `= NULL`
